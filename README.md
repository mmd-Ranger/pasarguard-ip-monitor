# PasarGuard IP Monitor Bot 🤖

ربات تلگرام برای مانیتور کردن تعداد IP متصل به هر یوزر پنل PasarGuard و ارسال هشدار خودکار در صورت عبور از حد مجاز (نشانه‌ی احتمالی اشتراک‌گذاری کانفیگ).

## امکانات

- بررسی خودکار هر ۱۰ دقیقه (قابل تغییر)، فقط روی یوزرهای آنلاین برای سرعت و کاهش فشار روی پنل
- بررسی موازی (چند درخواست هم‌زمان) برای افزایش سرعت
- ارسال هشدار تلگرامی هنگام عبور تعداد IP یکتای یک یوزر از حد مجاز (با فاصله‌ی زمانی بین هشدارها تا اسپم نشه)
- تنظیم حد مجاز IP از داخل خود ربات
- بررسی دستی یک یوزر خاص با نمایش دقیق IPها به تفکیک نود
- تاریخچه‌ی بررسی‌ها (به وقت تهران) برای اطمینان از عملکرد صحیح بررسی خودکار
- تنظیم آدرس پنل و اطلاعات ورود ادمین کاملاً از داخل خود ربات، بدون نیاز به ویرایش فایل
- محدود به مالک (owner)؛ هیچ کاربر دیگری امکان استفاده از ربات رو نداره
- بدون هیچ رمز یا توکنی داخل کد؛ همه چیز در فایل‌های تنظیمات محلی (گیت‌ایگنور‌شده) ذخیره می‌شه

## پیش‌نیاز

- یک سرور اوبونتوی ساده (حتی با منابع محدود کافیه)
- یک ربات تلگرام ساخته‌شده از [@BotFather](https://t.me/BotFather) (توکنش رو نگه دار)
- آیدی عددی تلگرام خودت (نه یوزرنیم) — از [@userinfobot](https://t.me/userinfobot) قابل دریافته

## نصب

```bash
git clone https://github.com/mmd-Ranger/pasarguard-ip-monitor.git
cd pasarguard-ip-monitor
chmod +x install.sh
./install.sh
```

اسکریپت نصب، پیش‌نیازها (پایتون، venv) و سرویس systemd رو خودش نصب و راه‌اندازی می‌کنه. فقط دو چیز ازت می‌پرسه: توکن ربات تلگرام و آیدی عددی خودت.

## اولین اجرا

بعد از نصب، تو تلگرام به ربات `/start` بزن. چون هنوز پنل معرفی نشده، به‌ترتیب ازت می‌پرسه:
1. آدرس پنل (بدون path، همون آدرس داشبورد؛ مثلاً `https://panel.example.com`)
2. یوزرنیم ادمین
3. پسورد ادمین

بعد از دریافت هر سه مورد، ربات خودش تلاش می‌کنه به پنل وصل بشه و نتیجه (موفق یا خطای دقیق) رو اعلام می‌کنه. این اطلاعات فقط روی سرور خودت ذخیره می‌شن و به هیچ‌جای دیگه‌ای ارسال نمی‌شن. هر وقت خواستی این‌ها رو تغییر بدی، از منوی ربات: **🛠 تنظیمات پنل**

## حذف کامل

```bash
cd ~/pasarguard-ip-monitor
chmod +x uninstall.sh
./uninstall.sh
```

## مدیریت سرویس

```bash
sudo systemctl status pasarguard-ip-monitor    # وضعیت
sudo journalctl -u pasarguard-ip-monitor -f    # لاگ زنده
sudo systemctl restart pasarguard-ip-monitor   # ری‌استارت
```

سرویس با `Restart=always` تنظیم شده؛ در صورت کرش، خودکار ظرف چند ثانیه دوباره راه‌اندازی می‌شه.

## سؤالات متداول

**آیا نیاز به دامین یا وب‌هوک دارم؟**
خیر. ربات با روش polling کار می‌کنه، پس نیازی به دامین، SSL یا وب‌هوک نیست.

**آیا رمزها امن هستن؟**
بله. هیچ رمز یا توکنی داخل کد نیست؛ همه چیز فقط روی سرور خودت، در فایل‌هایی که هیچ‌وقت commit نمی‌شن، ذخیره می‌شه.
