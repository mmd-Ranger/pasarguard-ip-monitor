# PasarGuard IP Monitor Bot 🤖

یه ربات تلگرام که خودش مرتب پنل PasarGuard رو چک می‌کنه، می‌بینه کدوم یوزرا IP زیادی وصل کردن (یعنی کانفیگشونو پخش کردن بین چندتا آدم)، و بهت خبر می‌ده.

## چیکار می‌کنه

هر ۱۰ دقیقه میره سراغ یوزرای آنلاین، می‌شمره هر کدوم چندتا IP یکتا وصلن. اگه از حد مجاز (پیش‌فرض ۸ تا، ولی خودت از تو تلگرام می‌تونی عوضش کنی) بیشتر بود، همون لحظه پیام می‌ده. یه دکمه هم داره که هر وقت خواستی یه یوزر خاصو دستی چک کنی و ببینی دقیقاً چه IPهایی داره.

فقط خودت باهاش کار می‌تونی بکنی، هرکی دیگه بهش پیام بده جوابشو نمی‌ده.

## چی لازم داری

- یه سرور اوبونتوی ساده (حتی ضعیف‌ترینش کافیه)
- یه ربات ساخته از [@BotFather](https://t.me/BotFather) — توکنشو نگه دار
- آیدی عددیت تو تلگرام (نه یوزرنیم) — از [@userinfobot](https://t.me/userinfobot) بگیرش

## نصب

```bash
git clone https://github.com/mmd-Ranger/pasarguard-ip-monitor.git
cd pasarguard-ip-monitor
chmod +x install.sh
./install.sh
```

پیش‌نیازها (پایتون، venv) و سرویس systemd رو خودش نصب می‌کنه؛ فقط توکن ربات و آیدی عددیتو ازت می‌پرسه.

## بعد از نصب

برو تو تلگرام `/start` بزن. چون هنوز پنل رو نمی‌شناسه، اول ازت آدرس پنل، بعد یوزرنیم ادمین، بعد پسورد رو می‌پرسه و خودش تست می‌کنه وصل می‌شه یا نه. این اطلاعات فقط رو سرور خودت می‌مونه. هر وقت خواستی عوضشون کنی هم از منوی ربات می‌تونی.

## حذف کامل

```bash
chmod +x uninstall.sh
./uninstall.sh
```

## اگه یه وقت خاموش شد

```bash
sudo systemctl status pasarguard-ip-monitor
sudo journalctl -u pasarguard-ip-monitor -f
```
خودش با کرش هم دوباره روشن می‌شه، نگرانش نباش.
