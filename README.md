# PasarGuard IP Monitor Bot 🤖

ربات تلگرام برای مانیتور کردن تعداد IP متصل به هر یوزر پنل [PasarGuard](https://github.com/PasarGuard) و هشدار خودکار وقتی یوزری از حد مجاز عبور کنه (اشتراک‌گذاری کانفیگ).

## امکانات

- بررسی خودکار هر ۱۰ دقیقه (قابل تغییر)، فقط روی یوزرهای **آنلاین** (نه همه‌ی یوزرها) برای سرعت و کم‌فشار بودن رو پنل
- بررسی موازی (چند درخواست همزمان) برای سرعت بیشتر
- هشدار تلگرامی وقتی تعداد IP یکتای یوزر از حد مجاز بیشتر بشه (با cooldown تا اسپم نشه)
- حد مجاز IP از داخل خود ربات قابل تغییره
- بررسی دستی یک یوزر خاص با نمایش دقیق IPها به تفکیک نود (برای راستی‌آزمایی)
- تاریخچه‌ی بررسی‌ها (به وقت تهران) برای اطمینان از این‌که چک خودکار واقعاً داره کار می‌کنه
- **تنظیمات پنل (آدرس + یوزر/پسورد ادمین) کاملاً از داخل خود ربات، بدون نیاز به ویرایش فایل**
- ربات فقط به مالک (owner) جواب می‌ده؛ هیچ‌کس دیگه‌ای نمی‌تونه ازش استفاده کنه
- هیچ رمز/توکنی داخل کد نیست؛ همه چیز تو فایل‌های تنظیمات محلی (که گیت‌ایگنور شدن) ذخیره می‌شه

## پیش‌نیاز

- یه سرور لینوکسی (VPS یا اختصاصی) با Python 3.10+
- یه ربات تلگرام ساخته‌شده از [@BotFather](https://t.me/BotFather) (توکنش رو نگه دار)
- آیدی عددی تلگرام خودت (نه یوزرنیم) — از [@userinfobot](https://t.me/userinfobot) بگیر
- دسترسی ادمین به پنل PasarGuard

## نصب

```bash
git clone https://github.com/<your-username>/pasarguard-ip-monitor.git
cd pasarguard-ip-monitor
chmod +x install.sh
./install.sh
```

اسکریپت نصب فقط دو چیز ازت می‌پرسه:
1. توکن ربات تلگرام
2. آیدی عددی خودت (owner)

بقیه‌ی چیزها (پکیج‌ها، محیط مجازی، سرویس systemd) رو خودش انجام می‌ده.

## اولین اجرا

بعد از نصب، تو تلگرام به ربات `/start` بزن. چون هنوز پنل رو معرفی نکردی، خودش ازت می‌پرسه:
- آدرس پنل (مثلاً `https://panel.example.com`)
- یوزرنیم ادمین
- پسورد ادمین

این اطلاعات فقط رو خود سرورت (تو فایل `panel_config.json`، که در `.gitignore` هست) ذخیره می‌شن و هیچ‌جا ارسال نمی‌شن.

هر وقت خواستی این اطلاعات رو عوض کنی، از منوی ربات: **🛠 تنظیمات پنل**

## مدیریت سرویس (اگه با systemd نصب کردی)

```bash
sudo systemctl status pasarguard-ip-monitor    # وضعیت
sudo journalctl -u pasarguard-ip-monitor -f    # لاگ زنده
sudo systemctl restart pasarguard-ip-monitor   # ری‌استارت
sudo systemctl stop pasarguard-ip-monitor      # توقف
```

سرویس با `Restart=always` تنظیم شده، یعنی اگه هر دلیلی کرش کنه، خودش ظرف چند ثانیه دوباره بالا میاد. بعد از ریبوت سرور هم خودکار روشن می‌شه.

## تنظیمات قابل تغییر (داخل `bot.py`)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `CHECK_INTERVAL_SECONDS` | 600 | فاصله‌ی بررسی خودکار (ثانیه) |
| `ONLINE_WINDOW_SECONDS` | 120 | یوزر تا چند ثانیه بعد از آخرین اتصال "آنلاین" حساب بشه |
| `ALERT_COOLDOWN_SECONDS` | 1800 | فاصله‌ی حداقلی بین دو هشدار برای یک یوزر |
| `MAX_WORKERS` | 12 | تعداد درخواست همزمان به پنل |

حد مجاز IP نیازی به ویرایش کد نداره، از داخل خود ربات (**⚙️ حد مجاز IP**) قابل تنظیمه.

## سؤالات متداول

**آیا نیاز به دامین یا وب‌هوک دارم؟**
نه. ربات با روش polling کار می‌کنه (خودش مرتب از تلگرام می‌پرسه)، پس نیازی به دامین، SSL، یا وب‌هوک نیست.

**اگه پنلم PasarGuard نباشه چی؟**
ربات چند تا الگوی endpoint احتمالی رو خودش تست می‌کنه (`CANDIDATE_IP_ENDPOINTS` تو `bot.py`) و اولین جوابی که ۲۰۰ برگردونه رو کش می‌کنه. اگه پنلت متفاوته، ممکنه نیاز به اضافه‌کردن endpoint خودش داشته باشی.

## امنیت

- هیچ رمز/توکنی تو کد یا ریپازیتوری نیست.
- `.env` و `panel_config.json` تو `.gitignore` هستن و هیچ‌وقت نباید commit بشن.
- ربات فقط به `OWNER_CHAT_ID` پاسخ می‌ده؛ پیام از هر چت دیگه‌ای نادیده گرفته می‌شه.
